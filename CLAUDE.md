# Project notes

## Company name

Use "Lehman Family LLC" for the company name in anything public facing: emails, page headings and titles, UI copy, Stripe-visible text, and docs that customers or tenants read. Do not use "Lehman Family Realty" or "Lehman Realty" there.

This applies to display copy only. Identifiers keep their names: Firebase project ids (`lehman-realty-dev`), GitHub environment names, the sender address (`support@lehmanfamilyllc.com`), and existing code names.
